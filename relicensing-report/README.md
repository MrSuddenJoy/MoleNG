# Relicensing Research Memo

Internal research memorandum on software relicensing, covering four areas:

1. **Legal foundations** — why relicensing is a copyright question (ownership, CLA vs DCO, irrevocable prior releases, direction-of-travel).
2. **Process** — a 7-step how-to for relicensing a project we own, with a "who do I need to ask?" decision tree.
3. **Feasibility & risk** — a 6-factor scoring matrix (0–18) grading any change Trivial / Moderate / Hard / Impractical, plus a "when to pay a lawyer" section.
4. **Third-party impact** — what to do when a dependency relicenses on us (the MongoDB → Elastic → HashiCorp → Redis pattern), sized by usage type.

Appendices: contributor-consent templates, a license-compatibility quick reference, and a glossary.
